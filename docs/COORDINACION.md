# Coordinación del proyecto

Tablón del proyecto: https://github.com/XumiFerre/Prova_1/issues . Leer la tarea y comentarios recientes antes de editar; crear o reutilizar un issue por tarea y vincular PR, pruebas, decisiones y pendientes. GitHub Issues no ofrece reservas atómicas: acordar un responsable por recurso antes de trabajo concurrente.

No publicar secretos. Una sesión de prueba de carga sin herramientas no ejecuta tareas ni acredita acceso al tablón. Una sesión operativa debe comprobar sus accesos y registrar resultados reales.
